# Buổi 20: Đồ Án Cuối Khóa

## Mục tiêu buổi học
- Học sinh trình bày đồ án cá nhân
- Nhận phản hồi và góp ý cải thiện
- Tổng kết khóa học, định hướng tiếp theo

## Thời lượng: 90 phút

| Thời gian | Nội dung |
|-----------|----------|
| 0-5 phút | Hướng dẫn trình bày |
| 5-70 phút | Học sinh trình bày đồ án (mỗi người ~10 phút) |
| 70-80 phút | Tổng kết khóa học |
| 80-90 phút | Định hướng học tiếp |

---

## Hướng Dẫn Trình Bày

### Mỗi học sinh trình bày (~10 phút)
1. **Giới thiệu** (1 phút): Tên project, mục đích
2. **Demo** (4 phút): Chạy thử, show các chức năng
3. **Code** (3 phút): Giải thích cấu trúc code, phần tâm đắc nhất
4. **Khó khăn** (1 phút): Gặp vấn đề gì, giải quyết thế nào
5. **Hỏi đáp** (1 phút)

### Tiêu chí đánh giá

| Tiêu chí | Điểm |
|----------|------|
| Chức năng hoạt động đúng | 30 |
| Giao diện (GUI hoặc Web) | 20 |
| Cấu trúc code (class, function, module) | 20 |
| Database (SQLite) | 15 |
| Sáng tạo & hoàn thiện | 15 |
| **Tổng** | **100** |

---

## Tổng Kết Khóa Học

### Những gì đã học

**Giai đoạn 1: Nền tảng**
- Biến, kiểu dữ liệu, điều kiện, vòng lặp
- List, Tuple, Dictionary
- Hàm, File I/O, Xử lý ngoại lệ

**Giai đoạn 2: OOP**
- Class, Object, Kế thừa, Đa hình
- Module, Package, pip

**Giai đoạn 3: Dữ liệu**
- SQLite Database
- API, JSON
- Xử lý dữ liệu nâng cao

**Giai đoạn 4: Ứng dụng**
- GUI với Tkinter
- Web app với Flask
- Deploy ứng dụng

---

## Định Hướng Học Tiếp

### Nếu thích Web Development
- Học thêm HTML/CSS/JavaScript
- Framework: Django (Python), React/Vue (JavaScript)
- Database: PostgreSQL, MongoDB

### Nếu thích Data Science / AI
- Thư viện: NumPy, Pandas, Matplotlib
- Machine Learning: scikit-learn, TensorFlow
- Khóa học: CS50 AI, fast.ai

### Nếu thích Mobile App
- Framework: Flutter (Dart), React Native (JavaScript)
- Hoặc: Kivy (Python) cho prototype

### Nếu thích Game Development
- Thư viện: Pygame (Python)
- Engine: Unity (C#), Godot (GDScript)

### Tài nguyên học thêm
- **Thực hành**: LeetCode, HackerRank, Codewars
- **Dự án**: Tự làm project cá nhân, đóng góp open source
- **Cộng đồng**: Stack Overflow, Reddit r/learnpython
- **Khóa học**: CS50 (Harvard), freeCodeCamp
