# Lộ Trình Học Python - Từ Cơ Bản Đến Tự Làm App

## Tổng quan
- Đối tượng: Sinh viên đại học năm nhất, đã biết Python cơ bản nhưng chưa vững
- Mục tiêu cuối khóa: Tự xây dựng được ứng dụng hoàn chỉnh
- Thời lượng mỗi buổi: 90 phút

---

## Giai đoạn 1: Củng cố nền tảng (Buổi 1-7)

| Buổi | Chủ đề | Mô tả |
|------|--------|-------|
| 1 | Ôn tập nền tảng Python | Biến, kiểu dữ liệu, input/output, toán tử, điều kiện if/else |
| 2 | Vòng lặp & chuỗi | for, while, break/continue, xử lý chuỗi |
| 3 | List, Tuple, Dictionary | Cấu trúc dữ liệu cơ bản, thao tác CRUD |
| 4 | Hàm (Function) | Định nghĩa hàm, tham số, return, scope biến |
| 5 | Xử lý file & ngoại lệ | Đọc/ghi file, try/except, quản lý lỗi |
| 6 | Git cơ bản | Git, GitHub, add/commit/push, branch, pull request, conflict |
| 7 | Mini Project 1 | Ứng dụng quản lý danh bạ (console) |

## Giai đoạn 2: Lập trình hướng đối tượng (Buổi 8-11)

| Buổi | Chủ đề | Mô tả |
|------|--------|-------|
| 8 | OOP cơ bản | Class, object, __init__, thuộc tính, phương thức |
| 9 | OOP nâng cao | Kế thừa, đa hình, đóng gói |
| 10 | Module & Package | Import, tạo module riêng, pip, virtual environment |
| 11 | Mini Project 2 | Ứng dụng quản lý sinh viên (OOP + file) |

## Giai đoạn 3: Làm việc với dữ liệu (Buổi 12-15)

| Buổi | Chủ đề | Mô tả |
|------|--------|-------|
| 12 | SQLite & Python | Kết nối database, CRUD với SQL |
| 13 | API cơ bản | Gọi API, xử lý JSON, thư viện requests |
| 14 | Xử lý dữ liệu | List comprehension, lambda, map/filter |
| 15 | Mini Project 3 | App tra cứu thời tiết (API + database) |

## Giai đoạn 4: Xây dựng ứng dụng có giao diện (Buổi 16-21)

| Buổi | Chủ đề | Mô tả |
|------|--------|-------|
| 16 | Tkinter cơ bản | Tạo cửa sổ, label, button, entry |

| 18 | Kết nối GUI + Database | Xây dựng app hoàn chỉnh với giao diện |

| 20 | Web app với Flask (2) | Database, login, deploy |
| 21 | Đồ án cuối khóa | Học sinh tự chọn đề tài, xây dựng app hoàn chỉnh |

## Ghi chú
- Mỗi giai đoạn kết thúc bằng 1 mini project để học sinh thực hành tổng hợp
- Lộ trình có thể điều chỉnh tốc độ tùy theo khả năng tiếp thu của học sinh
- Buổi cuối là đồ án cá nhân, học sinh trình bày sản phẩm
